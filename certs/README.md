# Сертификаты удостоверяющих центров

Всё, что лежит в этом каталоге, `entrypoint.sh` при старте контейнера
устанавливает в хранилище `mRoot` КриптоПро, а файлы `.crt` дополнительно
кладёт в системное хранилище и вызывает `update-ca-certificates`.

Нужно это для того, чтобы выстраивалась цепочка доверия при проверке подписи.

| Файл | Что это |
|---|---|
| `EasyCert.cer` | тестовый УЦ EasyCert — издатель демо-контейнера `keys/test1.000` |
| `certnew.cer` | тестовый УЦ ООО «КРИПТО-ПРО» |
| `kontur-q-2025.crt` | АО «ПФ «СКБ Контур» |
| `skbkontur-q-2025.crt` | АО «ПФ «СКБ Контур» |
| `sertum-q-2025.crt` | ООО «Сертум-Про» |

Все файлы содержат только открытые ключи удостоверяющих центров — секретов
в них нет.

Чтобы добавить свой корневой или промежуточный сертификат, положите его сюда
в формате DER (`.cer`) или PEM (`.crt`) и перезапустите сервис.
Конвертация при необходимости:

```bash
openssl x509 -inform der -in newcert.cer -out newcert.crt
```
