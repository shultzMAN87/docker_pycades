# Дистрибутив КриптоПро CSP

Сюда нужно положить файл **`linux-amd64_deb.tgz`** — он не входит в репозиторий,
потому что распространяется по лицензии КриптоПро.

Где взять: https://cryptopro.ru/products/csp/downloads
→ «Скачать для Windows» ▾ → **Linux DEB x64**
(нужна бесплатная регистрация на сайте).

После скачивания:

```
csp/
└── linux-amd64_deb.tgz
```

Имя файла должно быть именно таким — на него ссылается `docker/Dockerfile`.

Внутри архива ожидается каталог с `install.sh` и deb-пакетами. Скрипт
`scripts/install-csp.sh` находит его сам, поэтому вложенность и точное имя
каталога значения не имеют.

Версия CSP жёстко нигде не зашита: пакеты ставятся по маскам
(`lsb-cprocsp-devel_*.deb`, `cprocsp-pki-cades-64_*.deb` и т.д.),
так что обновление дистрибутива сборку не ломает.
